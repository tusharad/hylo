# hylo

[![Haskell CI](https://github.com/tusharad/hylo/actions/workflows/haskell.yaml/badge.svg)](https://github.com/tusharad/hylo/actions/workflows/haskell.yaml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A type-safe Haskell ORM and query composition engine leveraging recursion schemes (hylomorphisms) for expressive, mathematically sound SQL query generation and data mapping.

## Development

```bash
# Build
make build

# Run tests
make test

# Format code with Fourmolu
make format

# Check formatting
make format-check

# Lint with HLint
make lint

# Run formal verification gate
make gate
```
